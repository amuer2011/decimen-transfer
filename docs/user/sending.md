# 发送

支持任意非空文件，最大 64 MB；文本最大 4 MB，以 UTF-8 字节计。文件名和类型随内容传送，支持适合压缩的数据自动 gzip，接收端校验 SHA-256。

选择文件（也可拖放），或输入文本并点击“准备文本”，准备就绪后才可开始传输。编辑已经准备的文本会使旧内容失效，需要重新准备。

- **暂停**：隐藏二维码，停止推进序列，保留当前内容和会话。继续后接收端可以沿用进度。
- **终止**：停止动画并清空二维码与当前会话，可重新选择内容。
- **放大预览**：放大二维码；点击“退出放大”或 Esc 返回操作区。

发送期间锁定内容、帧率、每帧字节数和纠错设置。暂停时也不能修改这些设置，否则恢复时会产生新会话。显示大小可以随时调整，不影响接收进度。

默认 24 fps、1465 字节每帧。识别困难时先减少每帧字节数或降低帧率；提升纠错等级可能导致二维码容量不足，页面会报错并允许调整后重试。

发送端无法知道对方是否完成，也不能显示真实的接收百分比。确认接收端完成后手动终止发送。切换到其他页面前会确认是否终止会话。
