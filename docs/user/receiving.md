# 接收

只支持屏幕/窗口采集，不使用摄像头。网页版要求支持屏幕共享的浏览器，且通过 HTTPS 或 localhost 打开；桌面版直接使用内置窗口选择器。

在发送端开始传输后，点击“选择接收窗口”，选择二维码所在窗口。桌面版会显示缩略图，点击后预览并确认。取消选择会返回就绪状态，可以重试。

接收端锁定最先识别到的传输会话，避免其他二维码无意清除进度。若发送端重新开始传输，需要终止当前接收，再重新选择窗口。

- **暂停**保留已接收数据，不再解码。窗口共享仍然有效；继续后沿用同一会话。
- **终止接收**会提示清除已有进度，确认后释放共享与解码线程。取消确认会恢复原来的运行或暂停状态。
- 系统共享指示器结束共享，也会清除会话并允许重新选择。
- 用时、速率和预计剩余时间扣除本端暂停时间，均为估算。

收到完整数据后自动停止采集、解压并校验。只有校验通过才提供保存或文本复制。校验失败可重新接收。保存完成后桌面版可打开下载目录。

Win7 不支持现代窗口捕获保护。请优先选择发送窗口，避免整屏采集到接收端自己而出现反馈。
